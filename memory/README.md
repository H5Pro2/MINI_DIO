# Memory

Runtime memory files are written here during local experiments.

This folder is intentionally ignored by git except for this README. Memory is experimental state, not source code.

Passive family-component response observations may be generated locally as `passive_role_family_response_memory.json`. Their reproducible projection is stored with the numbered research finding, while the runtime-state JSON remains local.

Finding 2087 appends five contradictory 5m holdout observations without changing the 32 stable family-component response identities. The tracked projection now contains 222 observations and remains evidence only; it is not read by MINI_DIO.
