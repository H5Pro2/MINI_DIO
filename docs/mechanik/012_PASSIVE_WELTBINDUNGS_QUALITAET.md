# Passive Weltbindungsqualität

Stand: 2026-07-09

## Grund

Die Nullwelt-Gegenprobe zeigte:

```text
Feldfunktionen entstehen auch in entkoppelten Kontrollwelten.
```

Das ist kein Fehler.
Es bedeutet, dass das MCM-Feld interne Ordnung bilden kann.

Für die Forschung reicht die Feldfunktionsklasse allein aber nicht aus.
MINI_DIO muss zusätzlich passiv mittragen, ob eine Rolle eher realweltlich, nullweltlich, synthetisch oder gemischt gebunden ist.

## Mechanik

Die neue Lesung ergänzt die Preview-Anker-Tiefenmemory:

```text
Preview-Anker
-> Tiefe
-> Feldfunktionsqualität
-> Weltbindungsqualität
```

Gespeichert werden:

- `world_binding_quality`
- `world_binding_confidence`
- `world_binding_scores`
- `real_world_count`
- `null_world_count`
- `synthetic_world_count`
- `real_observation_share`
- `null_observation_share`
- `synthetic_observation_share`
- `unknown_observation_share`

## Qualitätsklassen

```text
realworld_bound
field_internal_null_order
synthetic_bound
mixed_binding
unclear_binding
```

## Wichtig

Diese Schicht ist passiv.

Sie ist:

- keine Handlung,
- kein Gate,
- keine Richtung,
- kein Entry-Signal,
- keine Motorik.

Sie verhindert nur, dass eine feldinterne Ordnung zu früh als realweltlich getragene Bedeutung gelesen wird.

## Forschungsnutzen

Durch diese Ergänzung kann MINI_DIO später unterscheiden:

```text
Diese Rolle ist stark, aber vor allem feldintern.
Diese Rolle ist stark und realweltlich rücklesbar.
Diese Rolle entsteht auch in Nullwelten.
Diese Rolle liegt zwischen realer Weltbindung und Feldselbstordnung.
```

Das ist ein wichtiger Schritt für ein reiferes MCM-System, weil Feldintelligenz nicht nur Verdichtung braucht, sondern Herkunft und Bindungsqualität.

## Nächster Prüfpunkt

Die neue Qualität muss mit denselben Realwelt- und Nullwelt-Memories erneut geprüft werden.
Entscheidend ist nicht, ob Nullwelten keine Rollen erzeugen, sondern ob MINI_DIO sie korrekt als andere Bindungsqualität erkennt.
