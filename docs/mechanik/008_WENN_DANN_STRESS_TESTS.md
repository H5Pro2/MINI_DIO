# 008 - Wenn-Dann-Stress-Tests

## Grundfrage

MINI_DIO soll nicht nur beobachtet werden. Zentrale MCM-Hypothesen müssen als konkrete Wenn-Dann-Experimente prüfbar werden.

Ein Stress-Test fragt nicht:

> Passt das Ergebnis zu meiner Idee?

Sondern:

> Wenn ich eine klar benannte Feldbedingung verändere, bleibt die Topologie stabil, kippt sie, driftet sie oder bildet sie eine neue geordnete Variante?

Damit wird MINI_DIO als experimentelle Feldtheorie behandelbar, nicht als Glaubenssystem.

## Zweck

Stress-Tests dienen vier Aufgaben:

- Hypothesen falsifizierbarer machen.
- Pareidolie-Vorwürfe methodisch schwächen.
- Topologie, Feldzeit, Nachhall und Rekopplung getrennt prüfen.
- Zeigen, ob das Feld nur rauscht oder auf veränderte Bedingungen strukturiert reagiert.

## Grundform

Ein sauberer Stress-Test braucht:

1. Ausgangszustand
   - Welche Welt, welche Memory, welche Topologie, welche Rollen?

2. Eingriff
   - Was wird verändert?
   - Beispiel: Rückführung dämpfen, Weltspannung erhöhen, Tonachse glätten, Rezeptoraufnahme schwächen, Sleep-Phase einfügen.

3. Erwartung
   - Was müsste passieren, wenn die Hypothese stimmt?
   - Was müsste passieren, wenn sie falsch ist?

4. Messung
   - Topologieklasse
   - Rollenbreite
   - Rekopplung
   - Strain
   - Feldzeit/Nachhall
   - Bedeutungsinseln
   - Wiederkehrende `dio_*`-Familien

5. Gegenprobe
   - gleiche Welt mit anderer Memory
   - andere Welt mit gleicher Memory
   - synthetische Kontrollwelt
   - Null-/Rauschwelt

6. Ergebnisgrenze
   - Befund
   - Indiz
   - nicht bewiesen
   - weiterer Test nötig

## Beispielhafte Wenn-Dann-Fragen

### Rückführung

Wenn die Rückführung im Feld gedämpft wird:

- kollabiert die Topologie?
- bleibt sie zentrumsnah?
- entsteht eine stabilere Randvariante?
- wächst offene Drift?

### Rezeptorik

Wenn die Rezeptoraufnahme stärker dämpft:

- sinkt Randrauschen?
- verliert das Feld Bedeutung?
- bleiben Kernfamilien erhalten?
- verschieben sich nur lokale Rollen?

### Tonachse

Wenn die auditive Achse geglättet wird:

- verschwindet Kippnähe?
- bleibt Nachhall sichtbar?
- entstehen weniger Hör-/Nachhallknoten?

### Weltspannung

Wenn dieselbe Memory mit ruhiger, stressiger und expansiver Welt gelesen wird:

- bleiben Kernfamilien stabil?
- driften Rollen?
- entstehen neue Brücken?
- verschiebt sich Zentrum-Peripherie?

### Offline-Feld

Wenn nach einem Real-Lauf eine Sleep-/Offline-Feld-Reorganisation läuft:

- werden alte Rekopplungsrollen gefestigt?
- entstehen neue Zwischenrollen?
- tauchen diese später in realer Welt wieder als ähnliche Feldrollen auf?

## Methodische Grenze

Ein einzelner erfolgreicher Stress-Test beweist die MCM nicht.

Stark wird der Befund erst, wenn mehrere Tests zeigen:

- gleiche Bedingungen erzeugen wiederkehrende Ordnung,
- veränderte Bedingungen erzeugen erwartbare Drift,
- Rauschwelt und Kontrollwelt verhalten sich anders,
- neue Rollen entstehen nicht beliebig,
- Kernfamilien bleiben teilweise wiedererkennbar.

## Aktueller Nutzen für MINI_DIO

Diese Testform macht die bisherige Forschung belastbarer:

- Topologie wird nicht nur behauptet, sondern unter veränderten Weltbedingungen geprüft.
- Feldzeit wird nicht nur beschrieben, sondern gegen Stress, Ruhe, Expansion und Kontrollwelten gelesen.
- Bedeutungsinseln werden nicht als fertige Wörter behandelt, sondern gegen Wiederkehr, Drift und Weltfenster geprüft.
- Rollentaxonomie wird nicht nur aggregiert, sondern gegen konkrete Tickfenster und Mehrwelt-Rücklesung kontrolliert.

## Regel für zukünftige Befunde

Jeder neue größere Befund sollte nach Möglichkeit eine Wenn-Dann-Form bekommen:

> Wenn diese Feldmechanik real trägt, dann müsste unter Veränderung X eine beobachtbare Reaktion Y auftreten.

Danach wird geprüft:

> Tritt Y wirklich auf, bleibt es aus, oder entsteht eine dritte geordnete Variante?
