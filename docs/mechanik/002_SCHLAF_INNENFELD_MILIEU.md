# 002 - Schlaf Als Entkoppeltes Innenfeldmilieu

## Zweck

Diese Datei legt die Schlaf-/Offline-Mechanik für MINI_DIO als organische Designgrenze fest.

Schlaf wird nicht als feste Ablaufkette verstanden, sondern als Feldmilieu:

```text
Außenwelt wird entkoppelt oder stark gedämpft.
Das Innenfeld bleibt aktiv.
Nachhallende Eindrücke können wieder ankoppeln.
Alte Episoden können resonieren.
Das Feld verarbeitet, rekoppelt, entlädt oder hält Spannung.
```

## Was Schlaf Nicht Sein Soll

Schlaf darf nicht mechanisch als starres Programm gebaut werden:

```text
nicht: Phase 1 -> Phase 2 -> Phase 3 -> Phase 4
nicht: Replay einer festen Datenfolge
nicht: künstliches Dauerrauschen
nicht: erzwungene Störung
nicht: künstliche Zusatzreize
```

Wichtig:

```text
MINI_DIO bekommt keine künstlichen Zusatzreize.
MINI_DIO bekommt keine absichtlich erzeugte Störung.
```

Der Schlafzustand soll regenerativ und feldgetragen sein, nicht belastend simuliert.

## Organische Grundannahme

Ein Organismus schaltet im Schlaf nicht einfach ab.

Er reduziert Außenweltkontakt, hält aber eine reaktive Erhaltungsform:

- Grundspannung des Systems,
- Nachhall alter Eindrücke,
- mögliche Resonanz alter Episoden,
- Entlastung oder Reorganisation,
- Verarbeitung geprägter Spuren,
- Rekopplung ohne Handlung.

Für MINI_DIO heißt das:

```text
Schlaf = entkoppeltes Innenfeld-Erleben ohne neue Außenwelt.
```

## Was Aktiv Werden Darf

Aktiv wird nicht das nächste Element einer Liste.

Aktiv werden darf, was im Feld Resonanz findet:

- aktueller Nachhall,
- ungelöste Feldspannung,
- wiederkehrende Episodenrolle,
- starke positive oder negative Prägung,
- alte kohärente Spur,
- offene Rekopplung,
- belastete Randnähe,
- noch nicht integrierte Bedeutungsinsel.

Das ist keine bewusste Auswahl und keine Handlung.

Es ist passive Innenfeldaktivierung.

## Was Nicht Direkt Eingebaut Wird

Es wird nicht programmiert:

```text
"spiele Episode X ab"
"sortiere jetzt Memory"
"träume jetzt Variante Y"
"erzeuge absichtlich Rauschen"
"simuliere eine Störung"
```

Stattdessen wird nur ein Milieu bereitgestellt:

```text
Außenwelt aus oder gedämpft
Innenfeld aktiv
Episode-Memory erreichbar
Nachhall messbar
Resonanz nach Feldnähe
keine Handlung
keine harte Reihenfolge
```

## Relevanz Für Die Bisherigen Offline-Tests

Die bisherigen Tests `1531` bis `1534` zeigen:

- leere Offlinephase rekoppelt zentrumsnah;
- gedämpfter Restreiz verlängert Nachhall;
- zyklischer Restreiz reaktiviert dieselbe Feldspur;
- Doppelspur-Offline fällt bisher noch in eine gemeinsame Rekopplungsrolle.

Diese Befunde zeigen eine stabile Basis, aber noch kein organisches Schlafmilieu.

Die nächste Stufe muss deshalb nicht mehr letzte Sinneslage abspielen, sondern Episodenrollen als Resonanzraum verfügbar machen.

## Ziel Der Nächsten Umsetzung

Die nächste technische Richtung lautet:

```text
sleep_field_environment
```

Diese Schicht soll:

- keine neue Außenwelt einspeisen;
- keine künstlichen Zusatzreize erzeugen;
- gespeicherte MCM-Episodenrollen passiv verfügbar machen;
- Nachhall und Feldnähe als Aktivierungsgrund lesen;
- Spannung, Rekopplung und Entlastung messen;
- keine Handlung und keine Richtung erzeugen.

## Prüfbare Fragen

1. Tauchen alte Episodenrollen im Schlaf wieder auf?
2. Bleiben sie getrennt oder fallen sie in `dio_14wanbg` zurück?
3. Entsteht Entlastung, wenn eine alte Spannung rekoppelt?
4. Bleibt belastete Randnähe länger aktiv?
5. Bildet sich neue Offline-Bedeutung ohne Außenwelt?
6. Oder bleibt der Schlafmodus primär zentrumsrückführend?

## Kurzform

```text
Schlaf ist keine Sequenz.
Schlaf ist ein entkoppeltes Innenfeldmilieu.
Das Feld darf alte Spuren passiv wieder berühren.
MINI_DIO bekommt keine künstlichen Zusatzreize.
```
