# Passive Feldfunktions-Memory

Stand: 2026-07-09

## Grundidee

MINI_DIO soll wiederkehrende Feldrollen nicht nur als Symbolhäufigkeit speichern, sondern als passive Feldfunktionsqualität mittragen.

Das bedeutet:

- Ein wiederkehrender Preview-Anker kann wie eine Milieuinsel wirken.
- Ein anderer Anker kann eher aktive Rekopplung tragen.
- Ein weiterer Anker kann noch offene Oberfläche bleiben.

Diese Lesung ist keine Handlung, kein Gate und kein Richtungssignal.

## Mechanische Trennung

Die neue Lesung sitzt in der passiven Preview-Anker-Tiefenmemory:

```text
Weltkontakt
-> Sehen / Hören / Rezeptorkontakt
-> MCM-Feldwirkung
-> Preview-Anker
-> Tiefe / Nachhall / Rekurrenz / Rekopplung
-> passive Feldfunktionsqualität
```

Nicht erlaubt:

```text
Feldfunktionsqualität -> Entry
Feldfunktionsqualität -> Richtung
Feldfunktionsqualität -> Gate
Feldfunktionsqualität -> Motorik
```

## Gespeicherte Qualitäten

Jeder gereifte Preview-Anker kann zusätzlich tragen:

- `field_function_class`
- `field_function_variant`
- `field_function_confidence`
- `field_function_scores`

Die erste Klassifikation unterscheidet bewusst grob:

```text
milieu_island
active_recoupling
open_surface
undetermined
```

Die Varianten beschreiben nur die aktuelle Lesung, zum Beispiel:

```text
quiet_deep_recoupling
distributed_active_recoupling
compact_carried_recoupling
strained_open_surface
```

## Warum das wichtig ist

Die letzten Rollenanalysen zeigten, dass einzelne Symbole nicht nur Namen sind.
Sie tragen unterschiedliche Feldfunktionen:

- `0hiolzy` wirkte wie eine ruhige, tiefe Milieuinsel.
- `1yxc2ug` wirkte wie verteilte, aktive Rekopplung.
- `0hvxln3` wirkte wie kompakte, stark getragene Rekopplung.
- `14sn1ov` wirkte wie visuell offene, beanspruchende Rekopplung.

Die neue Memory-Schicht speichert diese Art von Qualität allgemein, ohne die konkreten Symbolnamen fest zu programmieren.

## Forschungsstatus

Status: umgesetzt als passive Memory-Erweiterung.

Wichtig:

- Die Lesung ist weich und diagnostisch.
- Sie verändert keine Handlung.
- Sie darf später mit Mehrweltläufen geprüft werden.
- Sie soll zeigen, ob MINI_DIO Feldrollen über Welten hinweg als Funktionsräume mittragen kann.

## Nächster Prüfpunkt

Ein kontrollierter Folgelauf muss zeigen:

- ob bekannte Rollen ähnliche Feldfunktionsklassen behalten,
- ob neue Welten neue Varianten erzeugen,
- ob die Klassifikation stabil genug ist,
- ob sie nur Oberflächenhäufigkeit oder tatsächliche Feldqualität abbildet.
