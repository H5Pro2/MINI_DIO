# 003 - MCM Schlafregulation Als Forschungsgrenze

## Zweck

Diese Datei praezisiert die Schlaf-/Offline-Mechanik von MINI_DIO.

Gemeint ist kein fertiges Schlafmodell und keine Simulation biologischer Schlafphasen.

Gemeint ist eine reine Forschungsfrage:

```text
Wenn keine neue Aussenwelt einwirkt,
bleibt im MCM-Feld Aktivitaet sichtbar?
```

Die Staerke der Aktivitaet ist dabei nicht der erste Punkt. Entscheidend ist zuerst:

```text
Gibt es Aktivitaet?
Was wird aktiv?
Welche gespeicherten Erlebnisspuren tragen Bedeutung?
Entsteht daraus neue Bindung?
```

## Begriff

Der Arbeitsbegriff lautet:

```text
MCM-Schlafregulation
```

Damit ist keine Handlungsregulation gemeint.

Gemeint ist:

```text
entkoppelte Innenfeldverarbeitung
aus Nachhall, Episode-Memory, Feldnaehe und Rekopplung
```

## Zentrale Forschungsfrage

Die zentrale Frage lautet:

```text
Kann ein MCM-Feld gespeicherte Erlebnisspuren
ohne neue Aussenwelt weiterverarbeiten?
```

Daraus folgen vier Unterfragen:

1. Welche alten Episodenrollen werden aktiv?
2. Welche Rollen tragen im Offline-Milieu Bedeutung?
3. Bleiben Bedeutungen nur Rekopplung alter Weltspuren?
4. Oder entstehen neue weltunabhaengige semantische Bindungen?

## Weltunabhaengige Bedeutung

Weltunabhaengig heisst hier nicht beliebig und nicht halluziniert.

Es heisst:

```text
Die neue Bedeutung entsteht nicht aus neuer Aussenwelt,
sondern aus der inneren Rekombination bereits erlebter Feldspuren.
```

Eine solche Bedeutung waere erst dann relevant, wenn sie spaeter bei realem Weltkontakt wieder erkennbar wird:

```text
Offline entstandene Bindung
  -> spaeterer Weltkontakt
  -> "das kenne ich" im Feld
  -> wiedererkennbare MCM-Rolle
```

## Was Gemessen Werden Soll

Die MCM-Schlafregulation soll nicht nach Richtung, Handlung oder Ergebnis suchen.

Sie soll messen:

- aktive Episodenrollen,
- Aktivitaetsdauer,
- Rekopplung,
- Nachhall,
- Spannungsrest,
- neue Symbolbindung,
- Wiedererkennung spaeterer Weltkontakte,
- Trennung zwischen alter Spur und neuer Bindung.

## Harte Grenze

Nicht erlaubt:

```text
neue Aussenwelt einspeisen
Stoerung erzwingen
Traumsequenz fest programmieren
Handlung ableiten
Richtung ableiten
Offline-Bedeutung als Realitaet behandeln
```

Eine Offline-Bedeutung ist erst eine innere Bindung.

Sie wird nur dann wichtiger, wenn sie spaeter durch Weltkontakt wieder getragen wird.

## Kurzform

```text
MCM-Schlafregulation untersucht Aktivitaet im entkoppelten Feld.
Sie fragt, welche Erlebnisspuren Bedeutung tragen.
Sie prueft, ob daraus neue semantische Bindungen entstehen.
Diese Bindungen muessen spaeter an realem Weltkontakt rueckgekoppelt werden.
```
