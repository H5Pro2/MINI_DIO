# Befund 2001 - Mixed Binding als Übergangsfälle

Stand: 2026-07-09

## Frage

Nach Einführung der passiven Weltbindungsqualität wurde geprüft:

```text
Was bedeutet mixed_binding?
```

Wichtig ist die Trennung:

- `realworld_bound` bedeutet: die Rolle wird überwiegend aus Realweltkontakt getragen.
- `field_internal_null_order` bedeutet: die Rolle entsteht überwiegend aus Kontroll-/Nullweltordnung.
- `mixed_binding` bedeutet: Realwelt und Nullwelt tragen denselben Anker in vergleichbarer Stärke.

## Datengrundlage

```text
memory/1999_world_binding_probe.json
```

Diese Memory ist bewusst gemischt:

1. Sie enthält ältere reale Weltspuren.
2. Danach wurde ein realer BTC-Lauf ergänzt.
3. Danach wurde eine BTC-Nullwelt ergänzt.

## Lesung

`mixed_binding` ist kein Massenzustand.
Es trat in dieser Prüfung nur punktuell auf.

Die meisten Fälle liegen nicht im groben Randrauschen, sondern in ruhigen, tiefen Milieuvarianten:

```text
milieu_island / quiet_deep_recoupling
```

Das ist relevant, weil solche Rollen offenbar sowohl durch reale Weltphasen als auch durch feldinterne Kontrollordnung berührt werden können.

## Interpretation

Vorsichtige Lesung:

```text
mixed_binding markiert mögliche Übergangsfälle
zwischen feldinterner Ordnung und realweltlicher Rücklesbarkeit.
```

Das heißt nicht:

```text
Diese Rolle ist bewiesen real.
```

Sondern:

```text
Diese Rolle ist feldintern stabil genug,
um auch bei realem Weltkontakt wieder anschlussfähig zu erscheinen.
```

## Warum das für MINI_DIO wichtig ist

MINI_DIO bekommt damit eine zusätzliche Reifungsdimension:

```text
Feldfunktion
+ Weltbindungsqualität
+ später Drift-/Carry-Prüfung
= bessere Bedeutungsreife
```

Eine Rolle kann also zuerst feldintern entstehen, später realweltlich berührt werden und erst danach als tragfähigere Bedeutung reifen.

## Grenze

Die Fallzahl ist klein.
`mixed_binding` darf nicht überinterpretiert werden.

Der aktuelle Befund reicht nur für:

```text
Kandidatenstatus.
```
