# Vier-Asset-Sequenzmatrix 2025: XRP, DOGE, BTC, PAXG

Stand: 2026-07-08

## Grundfrage

Nach den lokalen Real-Sleep-Real-Sequenzen für XRP/DOGE und BTC/PAXG stellt sich die zusammenführende Frage:

```text
Welche Feldbewegungen wiederholen sich assetübergreifend,
und welche Weltgruppe färbt die Bewegung anders?
```

## Unterprüfung

Verglichen wurden vier lokale Anschlussfenster:

```text
5000-6000 -> 6000-7000
6000-7000 -> 7000-8000
7000-8000 -> 8000-9000
8000-9000 -> 9000-10000
```

Assets:

```text
XRP 2025 5m
DOGE 2025 5m
BTC 2025 5m
PAXG 2025 5m
```

## Matrix

| Anschluss | XRP | DOGE | BTC | PAXG |
|---|---|---|---|---|
| 5000-6000 -> 6000-7000 | verteilt_offen | mittlere_uebergangsphase | verteilt_offen | mittlere_uebergangsphase |
| 6000-7000 -> 7000-8000 | verteilt_offen | kompakt_nachhallend | verteilt_offen | verteilt_rekoppelnd |
| 7000-8000 -> 8000-9000 | verteilt_offen | verteilt_offen | verteilt_offen | verteilt_rekoppelnd |
| 8000-9000 -> 9000-10000 | mittlere_uebergangsphase | mittlere_uebergangsphase | mittlere_uebergangsphase | verteilt_rekoppelnd |

## Befund

Die Sequenzmatrix zeigt vier unterscheidbare Bewegungsarten:

```text
XRP:  länger getragene Offenheit, spätere Mittelung
DOGE: Rollenatmung zwischen Übergang, Kompaktheit, Offenheit und Mittelung
BTC:  ähnlich zu XRP, aber mit stärkerem Anfangsrollenraum
PAXG: breite Rollenbildung, die rekoppelnd bleibt
```

Damit wird eine wichtige Trennung sichtbar:

```text
Verteilte Rollenbreite ist nicht automatisch offene Drift.
Sie kann auch rekoppelnd getragen sein.
```

PAXG ist hier der klarste Gegenpol zu XRP/BTC:

```text
XRP/BTC: verteilt_offen -> spätere Mittelung
PAXG:    verteilt_rekoppelnd bleibt erhalten
```

DOGE bildet den beweglicheren Zwischenfall:

```text
Übergang -> kompakt -> offen -> Übergang
```

## Deutung

Die MCM-Feldordnung wirkt in diesen lokalen Sequenzen nicht wie eine starre Symboltabelle. Sie zeigt eine feldartige Bewegung:

- Rollenbreite kann entstehen.
- Rollenbreite kann offen bleiben.
- Rollenbreite kann rekoppelnd getragen werden.
- Kompaktheit kann zwischen offenen Phasen liegen.
- Endphasen können in mittlere Übergangsordnung laufen.

Das stützt die bisherige Arbeitshypothese:

```text
Topologie ist der stabile Rollenraum.
Lokale Sequenz ist die bewegliche Feldzeitform.
Rekopplung entscheidet mit, ob Breite driftet oder getragen wird.
```

## Grenze

Die Matrix ist ein passiver Forschungsbefund. Sie beschreibt Innenfeldbewegung nach Weltkontakt. Sie ist keine Handlungsregel, keine Richtungsaussage und keine Assetklassifikation.

## Folgeschritt

Als nächstes sollte geprüft werden, welche Rohweltmerkmale diese Sequenzrollen begleiten:

```text
Was unterscheidet verteilt_offen von verteilt_rekoppelnd?
Was unterscheidet kompakt_nachhallend von mittlerer Übergangsphase?
```

Ziel ist eine Rücklesung auf Sehen, Hören, Rezeptoraufnahme und MCM-Feldwirkung.
