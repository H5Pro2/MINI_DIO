# 1691 - Adaptive Milieu-Wechsel 2024/2025 Vergleich

Stand: 2026-07-07

## Zweck

Diese Pruefung vergleicht die Milieu-Relationswechsel aus den 2024-Folgewelten mit neuen 2025-Folgewelten.

Sie bleibt passiv:

```text
keine Handlung
kein Gate
keine Richtung
keine Strategie
```

## Hierarchie

1. Grundfrage: Bleibt die Wechselarchitektur ueber andere Weltjahre erhalten?
2. Unterpruefung: Treten dieselben vier Relationswechsel in 2025 wieder auf?
3. Folgeschritt: Pruefen, ob einzelne Familien wiederholt unter aehnlicher Rohweltspannung wechseln.

## Datengrundlage

2024:

- DOGE, XRP, PAXG und Stress
- jeweils Startfenster und Folgewelt
- Befund: [1688_ADAPTIVE_MILIEU_RELATIONSWECHSEL_ROHWELT.md](1688_ADAPTIVE_MILIEU_RELATIONSWECHSEL_ROHWELT.md)

2025:

- DOGE, XRP, PAXG und Stress
- jeweils Startfenster und Folgewelt
- Befund: [1690_ADAPTIVE_MILIEU_RELATIONSWECHSEL_ROHWELT_2025.md](1690_ADAPTIVE_MILIEU_RELATIONSWECHSEL_ROHWELT_2025.md)

## Ergebnis

Die vier Wechseltypen treten 2025 wieder auf.

```text
2024:
offen_und_gereift -> nur_gereift       215
nur_gereift -> offen_und_gereift       108
offen_und_gereift -> nur_offen          33
nur_offen -> offen_und_gereift          26

2025:
offen_und_gereift -> nur_gereift       177
nur_gereift -> offen_und_gereift       152
offen_und_gereift -> nur_offen          27
nur_offen -> offen_und_gereift          22
```

Damit bleibt die Wechselarchitektur erhalten, aber die Gewichtung verschiebt sich.

2024 dominiert staerker:

```text
offen_und_gereift -> nur_gereift
```

2025 waechst deutlich:

```text
nur_gereift -> offen_und_gereift
```

## Familienueberlappung

```text
Wechsel-Familien 2024: 262
Wechsel-Familien 2025: 241
gemeinsam: 155
Jaccard: 0.4454
```

Das ist weder eine starre Kopie noch freies Rauschen.

Lesung:

```text
Ein relevanter Familienkern kehrt wieder.
Die konkrete Milieu-Lage bleibt aber weltabhaengig beweglich.
```

## Ueberlappung nach Wechseltyp

```text
offen_und_gereift -> nur_gereift:
2024=168, 2025=142, gemeinsam=61, Jaccard=0.2450

nur_gereift -> offen_und_gereift:

nur_offen -> offen_und_gereift:
2024=23, 2025=21, gemeinsam=4, Jaccard=0.1000
```

Die stabilsten Wiederkehrspuren liegen in den beiden Hauptwechseln:

```text
offen/gereift wird enger gereift
gereift wird wieder offen/gereift
```

Die reinen Offenheitswechsel bleiben deutlich schwacher.

## Interpretation

Der Befund stuetzt drei Punkte:

1. Die Milieu-Wechsel sind nicht auf ein einzelnes Jahr beschraenkt.
2. MINI_DIO bildet keine starre Symboltabelle, sondern eine bewegliche Familien-/Milieu-Ordnung.
3. Offenheit und Reifung wirken als dynamische Schichten ueber wiederkehrenden Familien.

Fachlich wird damit die bisherige Lesung verstaerkt:

```text
Familie bleibt erkennbar.
Milieu verschiebt sich.
Rohweltkontakt veraendert die Lage der Familie im Feld.
```

## Grenze

Das beweist noch keinen Mechanismus.

Es zeigt:

```text
Die gleiche Wechselarchitektur laesst sich in einer weiteren Weltperiode wiederfinden.
```

Es zeigt noch nicht:

```text
Welche konkrete Rohweltursache den einzelnen Wechsel ausloest.
```
