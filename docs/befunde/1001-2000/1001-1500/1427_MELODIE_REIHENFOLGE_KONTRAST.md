# 1427 - Melodie Reihenfolge Kontrast

## Zweck

Diese Pruefung veraendert nicht nur eine einzelne Phase, sondern verschiebt die Melodieordnung deutlicher.

Grundfrage:

Bleibt die bisherige Bedeutungsnaehe erhalten, oder kippt die veraenderte Reihenfolge in eine neue Inselbildung?

## Aufbau

Referenz:

`rest -> wave_up -> block -> wave_down -> regular -> rest`

Leichte Variante aus `1426`:

`rest -> wave_up -> block -> wave_down -> irregular -> rest`

Staerkere Reihenfolge-Variante:

`rest -> block -> wave_down -> irregular -> wave_up -> rest`

## Schlussfolgerung

Mini-DIO liest die veraenderte Reihenfolge nicht als vollstaendig neue Insel.

Die bestehende Melodieordnung bleibt als Grundnaehe erhalten. Die Abweichung zeigt sich als leichte Zunahme von unruhiger tragender Feldwirkung und als Verschiebung der Nebenfamilien.

Damit sieht der Befund derzeit so aus:

Eine Melodie kann im MCM-Feld als geordnete Folge getragen werden. Wenn die Folge veraendert wird, entsteht zuerst Nachbarschaftsvariation. Neue Inselbildung tritt hier noch nicht auf.

## Grenze

Diese Pruefung nutzt eine synthetische Melodie-Welt.

Sie zeigt keine allgemeine Musikverarbeitung. Sie zeigt nur, dass eine veraenderte zeitliche Ordnung im Feld als nahe, aber leicht anders gespannte Bedeutungsstruktur gelesen wird.

## Wie es weitergeht

Als naechstes sollte die Melodie noch staerker gebrochen werden: Phasen doppeln, Ruhe entfernen oder Amplitude asymmetrisch machen. Dann pruefen wir, ob die Grundfamilie `dio_1fll` stabil bleibt oder ob eine neue Insel entsteht.
