# Bewertung 1280 - Sinnes-Topologie-Reproduktion

## Prueffrage

Bleiben die achsenspezifischen Sinnes-Signaturen ueber mehr Welten stabil, oder entstehen neue Mischsignaturen?

## Ergebnis

Der Kern bleibt stabil.

Die wichtigste Signatur bleibt:

```text
leise_scharf_feldduenn_getragen
-> zentrum_stabil
-> Hoeren hold, Sehen hold, Fuehlen hold
```

Sie waechst von `6886` Segmenten auf `23893` Segmente und bleibt dominant an `zentrum_stabil` gekoppelt.

Auch die Rekopplungsnaehe bleibt stabil:

```text
mittelton_mittelsicht_feldmittel_getragen
-> rekopplungsnaehe
-> Hoeren hold, Sehen hold, Fuehlen hold
```

## Neue Mischsignaturen

Die breitere Reproduktion erzeugt zusaetzliche Signaturen:

```text
laut_unscharf_feldstark_offen
-> offene_variante
-> Hoeren down, Sehen up, Fuehlen soften
```

```text
mittelton_unscharf_feldmittel_offen
-> offene_variante
-> Hoeren hold, Sehen up, Fuehlen hold
```

```text
leise_unscharf_feldduenn_offen
-> offene_variante
-> Hoeren up, Sehen up, Fuehlen up
```

```text
leise_unscharf_feldduenn_angespannt
-> spannungsrand_kippnaehe
-> Hoeren hold, Sehen up, Fuehlen hold
```

Das ist fachlich relevant: Nicht jede Rand-/Offenheitslage ist laut und feldstark. Es gibt auch duenne, unscharfe Rand-/Offenheitslagen. Dort waere nicht Daempfung, sondern genauere Aufnahme die passendere Tendenz.

## Interpretation

Die erste Memory war kein Zufall, aber sie war noch schmal.

Die Reproduktion zeigt:

- Zentrum bleibt sehr stabil.
- Rekopplungsnaehe bleibt stabil.
- Offenheit differenziert sich in mehrere Aufnahmeformen.
- Rand/Kipp differenziert sich in laute Ueberlastung und duenne/unscharfe Spannung.

Damit wird die Regulation genauer:

```text
laut + feldstark + angespannt -> Achsen herunterregeln
duenn + unscharf + offen -> Achsen hochregeln
getragen + stabil -> Achsen halten
```

## Methodische Grenze

Einige historische Segmentdateien enthalten fuer `avg_raw_field_intake` Nullwerte. Diese Nullwerte duerfen nicht als echte Feldlosigkeit ueberinterpretiert werden.

Trotzdem bleibt die Rollenbindung wertvoll, weil Rekopplung, Strain, Lautheit und Sicht weiterhin Rollenprofile bilden.

## Schluss

Die achsenspezifische Rezeptorpraeferenz ist reproduzierbar genug, um als naechste mechanische Schicht weitergefuehrt zu werden.

Sie sollte aber weiterhin passiv bleiben, bis ein isolierter A/B-Test zeigt, ob sanfte Rezeptorhaltung die Feldordnung verbessert oder verfaelscht.
