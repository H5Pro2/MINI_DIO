# 1942 - B-Fokus Nachbarfenster: Einordnung

## Befund

Die Nachbarprüfung zeigt eine zonale Restkopplung. `3000_4500` ist nicht nur ein einzelner Treffer.

Die drei gleich langen Fenster bilden eine kleine Feldabfolge:

```text
2800_4300 -> offener Randkontakt
3000_4500 -> gemeinsame SOL/BTC-Restkopplung
3200_4700 -> schmale Nullnähe-Reproduktion
```

## Interpretation

Das spricht gegen eine starre Punktlogik. Die Feldantwort verändert sich graduell über benachbarte Weltformen.

Die Mitte ist nicht automatisch stärker als die Nachbarn. Sie ist symmetrischer:

- SOL und BTC zeigen dort dasselbe Profil.
- Beide tragen 3 Kernpaare.
- Beide öffnen 1 Kernpaar.
- Beide verschieben 1 Kernpaar.

Links wird BTC stärker geöffnet. Rechts bleibt weniger Öffnung, aber noch Nullnähe.

## Bedeutung

Für MINI_DIO ist das wichtig, weil damit Weltpassung als Bereichsqualität lesbar wird:

```text
Weltformbereich + Hartkern-Brille -> Restkopplungsprofil
```

Das erweitert die bisherige Formel:

```text
Weltform + korrekt gelesene Hartkern-Brille -> Passungsprofil
```

zu:

```text
Weltform-Zone + korrekt gelesene Hartkern-Brille -> Verlauf der Passungsqualität
```

Damit bekommt die passive Memory mehr Tiefe: Nicht nur eine Weltlage trägt oder trägt nicht, sondern eine Zone kann unterschiedliche Trageformen ausbilden.
