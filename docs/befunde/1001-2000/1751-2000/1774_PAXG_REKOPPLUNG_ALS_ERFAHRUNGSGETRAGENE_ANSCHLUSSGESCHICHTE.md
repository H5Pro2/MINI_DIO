# PAXG-Rekopplung als erfahrungsgetragene Anschlussgeschichte

Stand: 2026-07-08

## Grundfrage

Nach 1773 war die synthetische Feindifferenz klarer:

```text
Mikrodifferenz erhöht Syntax,
öffnet aber noch keine Rollenbreite.
```

Die nächste Unterprüfung war deshalb:

```text
Was unterscheidet reale PAXG-Rekopplung
von synthetischer Feinheit, Feindifferenz und Koaktivierung?
```

## Vergleich

Verglichen wurden:

- synthetische Koaktivierung 1770,
- synthetisches Feinmilieu 1772,
- synthetische Feindifferenz 1773,
- reale PAXG-2024-Sequenzfenster.

Der kompakte Vergleich liegt in:

```text
reports/1773_feindifferenz_vs_paxg_rekopplung.csv
reports/1773_feindifferenz_vs_paxg_rekopplung.md
```

## Befund

1773 bleibt trotz höherer Syntaxmenge:

```text
1 Rolle
0 Kombinationen
adaptive_rekopplung_experience = 0.0
kompakt_nachhallend
```

PAXG 2024 bildet im rekoppelnden Fenster:

```text
5 Rollen
10 Kombinationen
adaptive_rekopplung_experience = 0.120333
verteilt_rekoppelnd
```

Wichtig ist dabei:

```text
PAXG ist nicht lauter.
PAXG ist nicht grober.
PAXG trägt Rollenbreite bei niedrigerer Rohweltenergie
und feinerer Anschlussgeschichte.
```

## Deutung

Die bisherige synthetische Suche zeigt drei getrennte Ebenen:

- mehr Zeichen erzeugen Syntaxvarianz,
- mehr Koaktivierung kann lokale Übergangsrollen öffnen,
- ruhige Feindifferenz stabilisiert, öffnet aber nicht automatisch.

Die reale PAXG-Rekopplung zeigt zusätzlich:

```text
Rollenbreite braucht eine Erfahrungs- oder Anschlusskopplung,
die mehrere Rollen gleichzeitig tragfähig hält.
```

Damit ist `verteilt_rekoppelnd` nicht einfach eine Folge von:

```text
leise Welt + Mikrobewegung
```

sondern eher:

```text
feine Weltbewegung + passende Anschlussgeschichte
+ erfahrungsgetragene Rekopplung
```

## Bedeutung für MINI_DIO

MINI_DIO unterscheidet hier sichtbar zwischen:

```text
Syntaxdichte
```

und:

```text
topologischer Rollenbreite
```

Das ist wichtig, weil Bedeutung im aktuellen Modell nicht als bloße Wortmenge gelesen wird.

Bedeutung entsteht erst, wenn Zeichen, Feldwirkung, Rollen und Anschlussgeschichte gemeinsam tragfähig werden.

## Grenze

Dieser Befund ist kein Beweis, dass PAXG generell die einzige rekoppelnde Weltklasse ist.

Er zeigt nur:

```text
Die bisher gebauten synthetischen Varianten treffen die reale PAXG-Rekopplung
noch nicht vollständig.
```
