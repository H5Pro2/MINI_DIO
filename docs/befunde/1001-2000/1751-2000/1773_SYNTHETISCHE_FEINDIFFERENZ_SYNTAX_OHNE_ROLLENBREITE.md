# Synthetische Feindifferenz: mehr Syntax ohne Rollenbreite

Stand: 2026-07-08

## Grundfrage

Nach Befund 1772 war sichtbar:

```text
Ruhige Feinheit allein bleibt kompakt.
```

Die nächste Unterprüfung war deshalb:

```text
Erzeugt ruhige Bindung mit kontrollierter Mikrodifferenz
mehr Rollenbreite?
```

## Umsetzung

Der synthetische Welt-Builder wurde um das Preset `rekopplungsbreite_feindifferenz` erweitert.

Die Welt bleibt insgesamt leise, enthält aber zusätzliche Mikrodifferenzen:

- kleine Richtungswechsel,
- leisen Gegenzug,
- kurze Range-Pulse,
- feine Driftbindung,
- ruhige Rollennähe,
- sanfte Rekopplung,
- Nachhallbindung.

Ziel war nicht eine lautere Welt, sondern eine feinere, unterscheidbarere Welt.

## Ergebnis

Die 1000er-Fenster zeigten über drei Varianten:

```text
24 von 24 Fenstern: kompakt_nachhallend
0 mittlere Übergangsphasen
0 verteilt offene Phasen
0 verteilt rekoppelnde Phasen
```

Die 2000er-Fenster zeigten:

```text
9 von 9 Fenstern: kompakt_nachhallend
```

## Auffälligkeit

Gegenüber 1772 stieg die Syntaxmenge deutlich.

Stärkste lokale Fenster:

```text
Syntax 22
Syntax 21
Syntax 16
Syntax 15
```

Stärkste breite Fenster:

```text
Syntax 26
Syntax 22
Syntax 19
Syntax 17
```

Trotzdem blieben alle Fenster bei:

```text
1 Rolle
0 Kombinationen
kompakt_nachhallend
```

## Rohwelt-Rücklesung

1000er-Fenster:

- Rollen: `1`,
- Kombinationen: `0`,
- Rekopplung: etwa `0.7559`,
- Nachhall: etwa `0.8145`,
- Basis-Weltenergie: etwa `0.7102`,
- Folge-Weltenergie: etwa `0.7003`,
- Range nahezu unverändert,
- Drift leicht fallend.

2000er-Fenster:

- Rollen: `1`,
- Kombinationen: `0`,
- Rekopplung: etwa `0.7568`,
- Nachhall: etwa `0.8361`,
- Basis-Weltenergie: etwa `0.7339`,
- Folge-Weltenergie: etwa `0.6609`,
- Range leicht fallend,
- Drift fallend.

## Befund

Die Feindifferenz-Welt erzeugt mehr innere Wörter als die glatte Feinmilieu-Welt.

Sie erzeugt aber keine Rollenöffnung.

Kurz:

```text
Mikrodifferenz erhöht Syntaxvarianz,
aber nicht automatisch topologische Rollenvarianz.
```

## Deutung

Damit verdichtet sich die Trennung:

- 1772: ruhige Feinheit -> kompakte Bindung, wenig Syntax,
- 1773: ruhige Feindifferenz -> kompakte Bindung, mehr Syntax,
- 1770: laute Koaktivierung -> lokale mittlere Übergangsphase,
- PAXG: ruhige rekoppelnde Breite -> mehr Rollen bei feiner Milieubindung.

Die fehlende Größe ist wahrscheinlich nicht einfach:

```text
mehr Mikrobewegung
```

sondern:

```text
Mikrobewegung mit tragender Anschlussgeschichte.
```

Oder technischer:

```text
Das Feld braucht nicht nur unterscheidbare Zeichen,
sondern eine Erfahrungskopplung,
die mehrere Rollen gleichzeitig als tragfähig halten kann.
```

## Bedeutung für MINI_DIO

MINI_DIO behandelt zusätzliche Zeichen nicht automatisch als Bedeutungstiefe.

Das ist wichtig:

```text
Syntax kann wachsen,
ohne dass das Feld topologisch breiter wird.
```

Damit wird Bedeutung weiter als Feldrolle gelesen, nicht als reine Zeichenmenge.

## Grenze

Der Befund gilt für die drei synthetischen Feindifferenz-Varianten A, B und C.

Er zeigt nicht, dass Mikrodifferenz unwichtig ist. Er zeigt, dass Mikrodifferenz ohne passende Rekopplungs- und Erfahrungslage noch nicht reicht.
