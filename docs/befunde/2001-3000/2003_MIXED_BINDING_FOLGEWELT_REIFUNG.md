# Befund 2003 - Mixed Binding gegen reale Folgewelten

Stand: 2026-07-09

## Frage

Nach Befund 2001 wurden fünf `mixed_binding`-Kandidaten gegen neue reale Folgewelten geprüft.

Die Leitfrage war:

```text
Reifen gemischte Feldanker durch realen Weltkontakt zu realworld_bound,
bleiben sie gemischt,
oder verschwinden sie?
```

## Datengrundlage

Ausgangs-Memory:

```text
memory/1999_world_binding_probe.json
```

Folgewelt-Memory:

```text
memory/2002_mixed_binding_follow_probe.json
```

Reale Folgewelten:

```text
btc_2025_follow_candidate_5000_6000.csv
doge_2025_follow_candidate_5000_6000.csv
xrp_2025_follow_candidate_5000_6000.csv
paxg_2025_follow_candidate_5000_6000.csv
```

## Gesamtbefund

Die Folgewelten erhöhen die realweltlich gebundenen Rollen deutlich:

| Zustand | Vorher | Nachher |
|---|---:|---:|
| `realworld_bound` | 117 | 172 |
| `mixed_binding` | 5 | 5 |
| `field_internal_null_order` | 1 | 1 |

## Kandidatenprüfung

Die fünf bestehenden `mixed_binding`-Kandidaten wurden durch die neuen Folgewelten nicht erneut getroffen.

Die gespeicherten Weltanteile blieben gleich:

```text
Realweltanteil etwa 0.4 bis 0.5
Nullweltanteil etwa 0.5 bis 0.6
```

## Lesung

Dieser Befund ist wichtig, weil er zwei Dinge trennt:

```text
1. Neue reale Folgewelten können zusätzliche realworld_bound-Rollen bilden.
2. Bestehende mixed_binding-Kandidaten reifen nicht automatisch mit.
```

`mixed_binding` ist damit kein automatischer Übergang nach Realweltbindung.
Es kann auch ein ruhender Grenzanker sein.

## Bedeutung für MINI_DIO

MINI_DIO gewinnt damit eine präzisere Reifungslogik:

```text
Feldintern stark
!= automatisch realweltlich reifend
```

Eine Rolle muss durch passenden Weltkontakt erneut getroffen werden, bevor ihre Bindungsqualität kippt.

Das spricht gegen eine reine Zählmechanik und für eine kontextabhängige Feldbindung.

## Konsequenz

Die nächste Prüfung sollte nicht wahllos neue Welten anhängen.
Sinnvoller ist eine gezielte Rücklesung:

```text
Welche Rohwelt-/Sinnesbedingungen hatten die fünf mixed_binding-Kandidaten ursprünglich?
```

Erst danach kann eine passende Folgewelt gesucht werden.
