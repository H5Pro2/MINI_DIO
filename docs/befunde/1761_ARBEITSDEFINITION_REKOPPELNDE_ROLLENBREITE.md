# Arbeitsdefinition: rekoppelnde Rollenbreite

Stand: 2026-07-08

## Grundfrage

Die letzten Sequenzprüfungen zeigten zwei Formen von Rollenbreite:

```text
verteilt_offen
verteilt_rekoppelnd
```

Die Arbeitsfrage ist:

```text
Was bedeutet rekoppelnde Rollenbreite im MCM-Feld?
```

## Vorläufige Definition

Rekoppelnde Rollenbreite bezeichnet eine passive MCM-Feldphase, in der mehrere Rollen und Kombinationen sichtbar werden, ohne dass diese Breite als lose Drift gelesen wird.

Kurz:

```text
Viele Rollen entstehen,
aber das Feld hält sie stärker zusammen.
```

## Beobachtete Merkmale

In den bisherigen Prüfungen zeigt `verteilt_rekoppelnd` typischerweise:

- mehrere Rollen und Kombinationen,
- höhere Rekopplung als `verteilt_offen`,
- stärkeren Nachhall,
- geringere Rohweltenergie oder ruhigere Basislage,
- weniger offene Entladung als bei `verteilt_offen`,
- stärkere Feldbindung trotz Breite.

## Abgrenzung zu verteilt offen

`verteilt_offen`:

```text
Breite entsteht, aber sie wirkt offener, weniger rückgebunden und stärker reiznah.
```

`verteilt_rekoppelnd`:

```text
Breite entsteht, aber sie wirkt getragener, nachhallender und stärker rückgeführt.
```

## Bedeutung für MINI_DIO

Diese Unterscheidung ist wichtig, weil sie zeigt:

```text
Komplexität ist nicht automatisch Überlastung.
Breite kann offen zerstreuen oder rekoppelnd getragen werden.
```

Damit wird die MCM-Feldlesung tiefer:

- Zentrum ist nicht nur Ruhe.
- Breite ist nicht nur Drift.
- Nachhall ist nicht nur Restspur.
- Rekopplung kann Breite stabilisieren.

## Forschungsgrenze

Das ist eine Arbeitsdefinition, kein endgültiger Beweis. Sie basiert auf den bisherigen lokalen Sequenzprüfungen aus 2024 und 2025.

Sie darf nicht als Regel im Code verwendet werden. Sie dient als passive Leseschicht für spätere Befunde.

## Folgeschritt

Als nächstes sollte geprüft werden, ob synthetische Welten ebenfalls rekoppelnde Rollenbreite erzeugen können. Wenn ja, wäre die Form nicht nur assetgebunden, sondern eine allgemeinere MCM-Feldbewegung.
